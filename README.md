# RansWorldSimulator

랜스월드 유저용 비공식 시뮬레이터입니다.

## 기능
- RP 상점 시뮬레이터
  - 자세히 보기 / 간단히 보기
  - 브라우저 저장 / 불러오기
  - JSON 파일 저장 / 불러오기
- 스크린샷 OCR 기반 경험치 효율 계산
  - 파일 첨부 / Drag & Drop / Ctrl+V
  - 브라우저 화면 공유를 이용한 랜스월드 창 1회 캡처 및 즉시 OCR
  - Lv / 진행률 / 현재 EXP / 총 EXP 후보를 교차검증하는 OCR Fusion 방식
  - OCR 로그 저장 지원
  - OCR 검산 완료 표기 개선 및 임시저장 기록별 세팅 메모 (탭 세션 동안 유지)
  - OCR 인식 실패 시 확대된 원본 EXP HUD 표시 및 기존 Lv·EXP 입력칸에서 수동 입력
  - 경험치 효율 임시저장, 최고 효율 대비 비교, 사냥터 정보 확인
- 환생 타이밍 추천
  - 분당 EXP 기반 환생 효율 비교 및 추천 1·2순위
  - 지금 환생 / 추천 시점 누적 RP/h 비교
- 파티퀘스트 EXP 반영
  - 전체 사용을 켜면 퀘스트 3종이 어려움·3회로 미리 선택되며 필요시 해제·변경 가능
  - 전체 미사용 시 EXP 보상 합계에 반영하지 않음
  - 파티퀘스트 3종(마왕발록·오르비스·네트의 피라미드) 독립 일일 3회 보상 및 09:00 갱신
  - 퀘스트별 체크·난이도·횟수 (기본 3회), 경험치 합산
  - 피라미드 보상: 쉬움 1,500억 / 보통 2,600억 / 어려움 4,000억 EXP
  - 오르비스: 쉬움 300억 / 보통 500억 / 어려움 700억 EXP (2026-11-26 보상 상향)
  - 현재 보상 주기마다 파티퀘스트별 0~3회 설정
  - 예상 환생 시각까지 매일 09:00 갱신분 자동 반복 반영
- 펫 특성 시뮬레이터 정식 탭
- 버전 표기 3회 선택 시 이미지 이스터에그

## 데이터
- 캐릭터 Lv별 다음 레벨까지 필요 EXP 데이터 표시 (Lv.351 필요 EXP 미확정)
- Lv.301~350 환생 RP는 보너스 적용 전 기본값으로 저장
- 환생코인 획득량 MAX(+500%)는 계산 단계에서 기본값에 ×6을 1회 적용
