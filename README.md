# RansWorldSimulator

랜스월드 유저용 비공식 시뮬레이터입니다.

## 기능
- RP 상점 시뮬레이터
- 스크린샷 OCR 기반 경험치 효율 계산
- 환생 타이밍 추천
- 파티퀘스트 EXP 반영
- 펫 특성 시뮬레이터 이스터에그

## 배포
정적 웹페이지이며 GitHub Pages로 배포합니다.

- 현재 버전: `v10.8`
- 진입점: `index.html`
- 별도 빌드 과정 없음
- OCR: 브라우저에서 Tesseract.js 사용

## 안내
본 사이트는 랜스월드 운영진의 허락을 받아 제작된 비공식 유저 제작 사이트이며, 공식 서비스와는 무관합니다.
